Original Grob G 103A Twin II Acro review model and cockpit
Owner: Talk Flying / Ty Frisby. Created 2026-11-01.

Both *-own.glb and *-own-tf.glb are original project geometry, UVs, dial art
and livery, generated by tools/own_models/build_grob103.py and companions.
No third-party mesh, reference photograph or manual image is embedded.
The aircraft shape/dimensions are measurements of the real machine, not a
licence to use the downloaded reference images. Those references do not ship.
Original house typography uses the locally installed Helvetica font rendered
into raster textures; font files are not embedded or redistributed.
E603 section numerical measurements: UIUC Airfoil Coordinates Database,
https://m-selig.ae.illinois.edu/ads/coord/e603.dat (reduced interpolation).

These assets have the same project ownership as the other original own models;
no separate public asset licence is granted here. See
 docs/models/grob103-own-PROVENANCE.md
for sources, measurements, limitations and reproduction commands.
Visual acceptance and game integration remain pending.
