# Free, commercial-OK 3D aircraft models — research (2026-10-02)

Scope: free models that may be shipped in a commercial iOS Unity game. Accepted licenses:
**CC0**, **CC BY 4.0** (credit required), **Sketchfab "Free Standard"** (commercial use OK, no credit
required, cannot redistribute the model file on its own — fine when it is embedded in a game build).
**CC BY-SA** is listed only where nothing else exists, and is marked CAUTION: commercial use is OK, but
modified versions of the model must stay BY-SA. Excluded: any NC or ND license, Editorial, "personal use",
GPL (FlightGear) models, and models ripped from games or stores.

How this was searched: the Sketchfab public search API (downloadable=true, license filter `by`, `cc0`,
`free-st`; no login), searches by author for prolific aviation modellers (helijah, manilov.ap,
ThalesMML, Spark_Customs), OpenGameArt, Poly Pizza, the Smithsonian 3D API, NASA-3D-Resources
(GitHub), and web search for CGTrader, Free3D and TurboSquid.
- **Smithsonian 3D**: no P-51 or any listed type. Aircraft there are only the Bell X-1, the 1903 Wright Flyer and similar.
- **NASA 3D Resources**: only the X-57. Nothing usable.
- **Poly Pizza / Kenney / Poly Haven**: only generic cartoon planes. No real types.
- **CGTrader / Free3D**: block scripted access. They need a manual browse with "Free" plus "Royalty Free" license filters (see Manual section).

Face counts are Sketchfab "faces" (≈ triangles). Every Sketchfab download gives auto-converted **glTF,
GLB and USDZ**, plus the author's original upload format (often FBX, OBJ or .blend). Sketchfab
**requires a free account login to download**.

Legend for "Commercial OK": **YES** = license allows it. **YES*** = license allows it, but see the
provenance note. Some uploaders may not own what they posted, so eyeball these before shipping.

> **Provenance warning: manilov.ap.** This account uploaded dozens of real aircraft types within a few
> days in Jan 2017 (A320, An-225, P-51, C-47, F-86, 737, Gee Bee …). Every model has a Wikipedia blurb
> and none has a making-of note. That pattern often means the models were converted from another
> sim's library. They are labelled CC BY, but their origin is unverified. Use them as placeholders, or
> accept the risk. **helijah** (Emmanuel Baranger, a long-time FlightGear aircraft author) publishes his
> own models. They are the most consistent family found here.

## Manual download steps (gated sites, which the owner must do)

**Sketchfab** (all Sketchfab rows above):
1. Sign in at sketchfab.com. A free account is enough.
2. Open the model URL from the tables above. Check the license line under the viewer still says
   **CC Attribution**, **CC0** or **Free Standard**. Authors can change it.
3. Click **Download 3D Model**. Choose **glTF** or **GLB** (best for Unity with the glTFast package), or
   **USDZ**. Use "Original format" only if it lists FBX.
4. Save to `assets-incoming/models/<aircraft-slug>/` and add a `LICENSE.txt` (copy the format from the
   downloaded folders) with the URL, author, license and the date you downloaded it.
5. Unity: install `com.unity.cloud.gltfast` to import GLB directly, or convert GLB to FBX in Blender.
   Decimate anything above about 100k faces (Blender Decimate modifier, ratio 0.3–0.5).

**BlendSwap** (Extra 330sc mirror, https://www.blendswap.com/blends/90608) needs a login. Use Sketchfab instead.

**CGTrader / Free3D / TurboSquid** (to fill the gaps by hand): set the search filter to **Free**, and
open each model's license tab. Accept only "Royalty Free" or "Royalty Free (no AI)" (CGTrader) or the
"TurboSquid 3D Model License". Reject any "Editorial" or "Personal use" license. Search terms worth
trying: `Pitts S-2`, `Pawnee`, `Decathlon`, `Seminole`, `Glasair`, `Cassutt`, `MQM-107`, `BQM-74`.

**Not usable:** FlightGear aircraft (GPL, which conflicts with App Store distribution of a closed game),
FS2004/FSX/X-Plane freeware add-ons (no reuse rights), and the Apple AR Quick Look gallery (no license).
