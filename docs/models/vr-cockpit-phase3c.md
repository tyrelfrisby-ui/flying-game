# Great Lakes P3c — photo geometry, 2026-11-02

All three `great-lakes-like-own*.glb` assets are generated by the CPU path.
References studied: `gl_cockpit.png`, `gl_cabane_gear_side.png`,
`gl_cockpits_above.png`, `gl_cabane_closeup.png` in the operator reference folder.
Dimensions are photo-informed estimates. No visual/VR gate approval is claimed.
Coordinates below: builder metres, X forward, Y left, Z up.

## Windshields

Two continuous curved acrylic sheets, one mesh/primitive/connected component each:
`Windscreen_Front`, `Windscreen_Rear`. No `Windscreen_Frame` nodes, top/side
borders, bend posts or bezel. Original low padded cockpit coamings/side rails
are preserved separately as `GL3c_Coaming_Padding`; they are not acrylic borders.
Five 6 mm diameter base screw heads per sheet. Clear double-sided acrylic uses
alpha 0.12 fallback, transmission 0.96, IOR 1.49, roughness 0.09. Transmission
support depends on the importing shader; no Unity shader changes were made.

Front centre height above deck: 125 mm; rear: 175 mm. Front top edge drops
8 mm from centre to sides; rear drops 30 mm (the implemented sinusoidal crown,
not an inferred real-aircraft radius). Absolute crown Z: front 0.32625 m (v1),
0.32650 m (red/white); rear 0.37500 m. Each sheet has 65 lateral by 13 vertical
samples, a smooth plan curve, and 15 mm aft rake at its centre. Bases wrap
outside the forward cockpit corners and follow the actual painted skin.

Important base difference: v1 has elliptical openings at X [-1.33,-0.97] and
[-2.08,-1.64]; older red/white bases have wider openings at [-1.28,-0.95] and
[-2.03,-1.48]. Screens follow each existing base; cockpit/control geometry is
not moved to force a common opening.

from skin fittings at X +0.10 / -0.70, Y ±0.33, to the existing oleo top pin
(-0.20, ±0.62, -0.60). The existing oleo and moving axle/compression-strut

## Cabane

Six 24 mm OD tubes: `Cabane_Leg_{Fwd,Aft,Diagonal}_{L,R}`. Aft and diagonal
share ONE clevis per side at X -0.80, Y ±0.33, just ahead of the front screen.
Forward fitting is at X -0.12, Y ±0.33. Upper pins stay exactly at
(-0.15, ±0.70, 0.62) / (-0.80, ±0.70, 0.62). Lower pin Z is actual skin Z
+14 mm, inside a bolted clevis. Conforming 54×38×3 mm pads use a 7×7 skin grid.

Axis-to-skin distance is intentionally nonzero after: the tube now lands in

These are distances to triangulated geometry, not photo measurements.
Per-asset full precision results are in `vr-cockpit-phase3c-checks.json`.

## CPU verification and operator commands

`check_gl_p3c.py`: glTF validation; absent frame nodes; one connected sheet
per screen; actual crown Z/drop; tube caps reach both endpoints; endpoint
within 2 mm of its fitting; fitting pad vertices, edge midpoints and face
centres within 2 mm of skin; unchanged gear pin contacts; new triangles
clipped against cockpit aperture extrusions (Z -0.02 through 0.70 m); exact
triangle/segment intersection against both eye-to-panel centre sight lines.
Preserved old padding is excluded from the new-geometry aperture test.
Older livery bases lack Eye nodes: checker uses v1 authored eye positions,
Front (-1.22,0,0.27), Rear (-1.95,0,0.29), as documented estimates there.
This is a geometric check, not an anthropometric/VR approval.

`vr_phase3.py` now avoids appending identical entries to the shared rig when
regenerating multiple base liveries. Existing entries, including legacy
repetitions, are retained. P3a geometry and shared rig content are preserved.

Run from this worktree, with no Blender needed:

```sh

/tmp/topo-venv/bin/python tools/own_models/vr_cockpit.py
/tmp/topo-venv/bin/python tools/own_models/check_gl_p3c.py

```

The operator can reset ONLY the three model GLBs from `0a1a7b4` before that
CPU command when doing a clean canonical rebuild. Do not reset rig JSON or
other current source files. The update is byte-idempotent after application.

Blender is operator-only. To render BEFORE 3a9e746 and AFTER with the same
standalone script/cameras, without changing worktree revisions:

```sh
mkdir -p /tmp/gl3c-before-assets
for name in great-lakes-like-own great-lakes-like-own-red-sunburst great-lakes-like-own-white-stripes; do
  git show "3a9e746:unity/Assets/_Project/Resources/Models/great-lakes-like/$name.glb" > "/tmp/gl3c-before-assets/$name.glb"
  PYTHONDONTWRITEBYTECODE=1 blender -b --factory-startup --python tools/own_models/render_gl_p3c.py -- "/tmp/gl3c-before/$name" --model "/tmp/gl3c-before-assets/$name.glb"

done
```
