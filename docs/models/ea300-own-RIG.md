# Extra EA 300 own model: cockpit rig (extra-300-like-own*.glb, v15)

Generated from `docs/models/ea300-own-rig.json` (written by `EA_RIGJSON=<path> EA_LIVERY=unmarked blender -b --python tools/own_models/build_ea300.py`; the rig is the same for every livery). Rig code: `tools/own_models/ea_rig.py` (exec'd post-yaw, after the hinge loop, just before export); cockpit geometry: `tools/own_models/ea_cockpit.py` (exec'd pre-yaw right after the shell cockpit); dial art and needle maps: `tools/own_models/ea_dialmaps.py` + `make_ea_dials.py` (art/ea-dial-*.png, ea-compass-band.png, ea-avx-com.png, ea-avx-xpdr.png); default sequence card: `make_ea_seqcard.py` (art/ea-seqcard-default.png). Template: `great-lakes-own-RIG.md` v13.1.

Conventions (same as the GL / 2-33): glTF frame (Y up; nose toward -X, so +X = aft, +Y = up, +Z = port, the pilot's left). Every moving node has its origin on its hinge/pivot, so `kind: rot` = rotate the node's LOCAL rest pose by `angle_deg = interp(map, param)` about `axis_gltf` (unit vector, model space at rest, right-hand rule); `kind: move` = translate by `interp(map)` metres along `axis_gltf`. Maps are piecewise linear and clamp at the ends, except nodes with extra `rig_map_extrapolate` (altimeter hands, radio / transponder knobs: unbounded) and `rig_map_wrap` 360 (compass card). Every node carries the same data as glTF extras (`rig_param`, `rig_axis_gltf` or `rig_move_axis_gltf`, `rig_map_param`, `rig_map_deg` / `rig_map_m`, `rig_param_model`, `rig_desc`). The hinged surfaces (Aileron_L/R, Elevator_L/R, Rudder; v13 hinges, unchanged) and the Canopy carry `hinge_axis_marker` (`<name>_HingeAxis`, an empty at the far end of the hinge line, so axis = marker - origin). Child nodes are already parented in the GLB: apply LOCAL rotations (Stick_F/R ride on StickRoll_F/R; Brake_* ride on their Pedal_*; CanopyLock_F/R and the canopy meshes ride on Canopy; needles ride on Instruments_Front/Rear).

Hierarchy: `Cockpit` (group) > `Instruments_Front`, `Instruments_Rear`, `Controls` (StickRoll_F > Stick_F, StickRoll_R > Stick_R, Pedal_* > Brake_*, Throttle_F/R, Trim_R, FuelSel_F/R), `Interior` (Cockpit_Shell = the v12 shell cockpit tub, Cockpit_Interior = all static v15 cockpit parts in one multi-material mesh, Footwell_Liner), CanopyRelease_F/R, `Eye_Front`, `Eye_Rear` (camera points; `Eye_Rear` has extra `default_view: true`). Canopy (root empty on the right-sill hinge) > Canopy_Glass, Canopy_Frame, CanopyLock_F, CanopyLock_R. Static: Canopy_Sill (the fixed rail round the opening), Window_Glass / Window_Frame (the fixed fuselage side windows that used to be part of the canopy mesh). The surface mesh names (Aileron_*, Elevator_L/R, Rudder) are unchanged.

60 rig nodes + 2 displays + 1 sequence card slot. `est` = E: the value (range, layout, sense or pivot placement) is my estimate, not read off a drawing, POH or manual. Not estimated: the EA 300/L POH control travels (aileron ±30, elevator ±25, rudder ±30 deg), instrument markings (ASI, RPM, MP, oil, CHT, G-meter), the one-piece canopy hinged on the right with red lock handles (AAIB G-ZXCL, Wagstaff egress notes), the controls present in each seat (POH).

## Params (all from the sim; front and rear cockpits always show the same value)
- Controls: `aileron` -1..+1 (+1 roll right: stick top right, left aileron TE down, right TE up), `elevator` -1..+1 (+1 stick aft, elevators TE up), `rudder` -1..+1 (+1 right pedal forward, rudder TE to starboard), `brake_left` / `brake_right` 0..1 (toe brakes, 1 = pressed), `throttle` 0..1 (0 idle / aft), `prop` and `mixture` 0..1 (rear-panel push-pull verniers, 1 = in / full forward), `trim` -1..+1 (+1 nose up; rear seat only, right ledge), `fuel_selector` 0 / 1 / 2 (detents, E: e.g. OFF / WING / ACRO&CENTRE; both seats), `magneto` 0..4 (0 OFF, 1 R, 2 L, 3 BOTH, 4 START; START springs back), `master` 0 / 1.
- Canopy: `canopy_open` 0..1 (1 = 100 deg open to the right), `canopy_lock` 0 / 1 (1 = locked; the sim should refuse `canopy_open` > 0 unless 0), `canopy_jettison` 0..1 (pull of the red release; at 1 the sim detaches the `Canopy` node with everything under it, i.e. glass + frame + both lock levers, and throws it clear; Canopy_Sill and the side windows stay). Canopy carries extras `rig_jettison_param: canopy_jettison` and `rig_jettison_desc`.
- Instruments: `airspeed_kias` (0..260), `altitude_ft` (unbounded), `vsi_fpm` (±3000), `rpm`, `manifold_inhg`, `oil_press_psi`, `oil_temp_f`, `cht_f`, `fuel_centre_frac` (centre / acro tank 0..1), `heading_deg` (card drum, reverse-sensing like a real wet compass), `turn_rate_dps` (±6), `slip_ball` -1..+1, `g_load` (-10..+10), `g_max_seen` / `g_min_seen` (tell-tales; the sim keeps the running max / min and the reset).
- Avionics (rear panel): `com_freq_mhz` (118.000..136.990 active), `com_standby_mhz`, `com_volume` 0..1, `xpdr_squawk` (4-digit octal), `xpdr_mode` (OFF / SBY / ON / ALT), `xpdr_knob_clicks` (integer, free-running). - Seats: front panel = ASI, G-meter, altimeter (Ty, 2026-10-30) plus tach and oil (photo layout); throttle, fuel selector, stick, pedals with toe brakes, canopy lock and release. Rear (PIC) panel = full panel: ASI, altimeter, VSI, turn coordinator, G-meter, MP, tach, oil, CHT, fuel, mag key, master, prop + mixture verniers, panel-mount wet compass (lower right, under the radio heads), sequence card holder (centre of the dash top), radio + transponder heads; throttle (left ledge), trim (right ledge), fuel selector (centre stack), stick, pedals with toe brakes, canopy lock and release.
